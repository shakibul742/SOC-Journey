# SOC Analyst Portfolio

> **Status:** Actively learning, practicing, and sharpening my skills as an aspiring Security Operations Center (SOC) Analyst.

Welcome to my cybersecurity portfolio. This repository serves as a centralized log of my hands-on investigations, alert triage exercises, and incident response case studies.

---

## Core Competencies

- **Alert Triage:** Distinguishing true positives from false positives via SIEM analysis.
- **Log Analysis:** Investigating HTTP, firewall, endpoint, and proxy logs.
- **Threat Hunting:** Identifying Indicators of Compromise (IOCs) and mapping to MITRE ATT&CK.
- **Incident Response:** Formulating containment and remediation strategies.
